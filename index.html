Game Scripts
PlayerMovement Environment

First-person character controller. Handles WASD/arrow key movement, running (Shift), gravity, and mouse-look camera rotation via the New Input System.

PlayerHealth Environment

Lives system with 3 lives by default. Respawns the player at their start position when hit; triggers game-over on final death.

PlayerNoise Environment

Tracks the player's noise level based on movement speed. Silent when still, moderate while walking, loud when running — feeds into enemy AI logic.

PlayerHiding Environment

Stub component tracking whether the player is hidden. Toggleable via the Inspector for testing, with full input integration planned.

DoubleDoorToggle Environment

F-key interaction for double-door pairs. Smoothly animates doors open/closed with easing, detecting which direction swings away from the player.

MouseDrivenDoor Environment

Mouse-drag door interaction. Players grab and physically push/pull doors with left-click and mouse movement, with smooth damping and highlight material support.

MouseLook Environment

Camera rotation controller (legacy/supplemental). Locks the cursor and maps mouse movement to first-person head rotation.

HorrorCrosshair UI

Procedurally generated crosshair drawn on a Screen-Space canvas. Supports a glowing dot or a 4-point laser-star style with optional pulsing animation.

PlayerCrouch Environment

Toggle-crouch using Left Ctrl or C. Smoothly shrinks the collider, lowers the camera proportionally, slows movement to crouch speed, and prevents standing up under a ceiling. Fully compatible with the New Input System.

FixDoubleDoorSetup Editor

Editor batch tool that auto-wires DoubleDoorToggle components across all door prefabs in the scene.

FixMouseDrivenDoorHinges Editor

Editor utility that corrects hinge root references on MouseDrivenDoor components throughout the project.
